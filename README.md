# 법규검토 워크벤치

프로젝트(사업) 정보를 입력하면, **법제처 국가법령정보 공동활용 Open API**로 국가법령과 지자체 조례를 실시간 검색·선택하고, 이를 정리한 **검토 보고서**(인쇄/PDF)를 만들어주는 웹앱입니다.

```
[브라우저] → /api/law-search, /api/law-detail (서버리스 함수) → law.go.kr DRF API
```

브라우저에서 law.go.kr을 직접 호출하면 CORS 때문에 막히고, OC 키도 노출되기 때문에
**서버(API 라우트)를 한 번 거치도록** 구성했습니다. OC 키는 서버 환경변수에만 저장되고
클라이언트 코드에는 전혀 노출되지 않습니다.

---

## 1. 로컬에서 바로 실행해보기

```bash
npm install
node server.js
```

`.env.local` 파일에 이미 `LAW_API_OC=choi2372` 가 들어있습니다. 다른 계정으로 바꾸려면
이 값만 수정하세요. 브라우저에서 http://localhost:3000 접속.

## 2. Vercel로 배포하기

1. 이 폴더를 GitHub 저장소로 올립니다 (`.env.local`은 `.gitignore`에 포함되어 있어 올라가지 않습니다 — OC 키가 그대로 공개 저장소에 노출되지 않게 하기 위함입니다).
2. https://vercel.com 에서 New Project → 방금 만든 저장소 선택 → Import.
3. **Environment Variables**에 아래 항목을 추가합니다.
   - `LAW_API_OC` = `choi2372` (또는 발급받은 다른 OC 값)
4. Deploy. 완료되면 `https://프로젝트명.vercel.app` 주소로 바로 접속 가능합니다.

별도 빌드 설정은 필요 없습니다 — `api/*.js`는 자동으로 서버리스 함수로,
`public/` 폴더는 자동으로 정적 파일로 인식됩니다.

---

## 3. ⚠️ 반드시 확인해야 할 것 — API 응답 필드명

법제처 Open API 공식 가이드 페이지(open.law.go.kr)는 자동 접근을 막아두고 있어,
이 앱을 만들면서 **실제 응답 XML의 정확한 필드명을 실물로 검증하지 못했습니다.**
`public/app.js` 상단의 `FIELD_MAP`에 있는 필드명(`법령명한글`, `법령일련번호` 등)은
공개 레퍼런스 구현체들을 참고해 정리한 "가장 유력한 추정값"입니다.

처음 배포 후 검색을 해봤을 때:

- **정상 작동** → 그대로 쓰시면 됩니다.
- **제목이 비거나 이상하게 나옴** → 검색 결과 카드의 "원문 보기" 버튼을 눌러 실제 JSON
  구조를 확인한 뒤, `app.js`의 `FIELD_MAP` 안 해당 필드 후보 배열 맨 앞에 실제 태그명을
  추가해주세요. 예:

  ```js
  title: ["법령명한글", "법령명", "법령약칭명"],
  // 실제 응답에 "법령명_한글" 이라는 필드가 온다면 맨 앞에 추가
  title: ["법령명_한글", "법령명한글", "법령명", "법령약칭명"],
  ```

  한 번만 보정하면 이후에는 정상적으로 동작합니다. 이 구조로 짠 이유가 바로
  이 보정 작업을 코드 한 줄만 고치면 되게 하기 위해서입니다.

- 자치법규(`target=ordin`) 검색은 지역명 + 키워드를 함께 넣는 방식(예: "전주시 건축 조례")이
  가장 안정적입니다. 지역 단위 필터 파라미터명도 공식 문서로 확정하지 못했기 때문에,
  검색어 자체에 지자체명을 포함시키는 방식을 기본으로 구현해두었습니다.

## 4. 화면 구성

- **좌측**: 사업명 / 대상 지자체 / 용도 / 연면적 / 규모 등 프로젝트 개요 (자동 저장)
- **중앙**: 국가법령 검색 탭 (건축법 등 자주 쓰는 법령 원클릭 검색칩 포함) / 자치법규 검색 탭
- **우측**: 보고서에 추가한 법령·조례 목록
- **검토 보고서 보기**: 표지 + 적용 법령/조례 목록 + 종합 검토의견(직접 작성) + 인쇄 버튼

검토의견(3번 섹션)은 **의도적으로 자동 생성하지 않고 직접 작성하는 칸으로 남겨두었습니다.**
법규 적합/부적합 판단은 실무자의 책임 하에 원문 조문을 직접 확인하고 작성해야 하는
영역이라고 판단했기 때문입니다. 이 앱은 "관련 법령·조례를 빠르고 정확하게 찾아 정리"하는
데까지를 자동화합니다.

## 5. 폴더 구조

```
kc-law-review/
├── api/
│   ├── law-search.js   # lawSearch.do 프록시 (검색)
│   └── law-detail.js   # lawService.do 프록시 (본문 상세)
├── public/
│   ├── index.html
│   ├── styles.css
│   └── app.js           # FIELD_MAP 보정은 이 파일 상단에서
├── server.js             # 로컬 실행용 (node server.js)
├── vercel.json
├── .env.example
└── .env.local            # 실제 OC 값 (배포/커밋 시 제외됨)
```
